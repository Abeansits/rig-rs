# Changes from OpenRig

This project is being rewritten in Rust from OpenRig v0.6.9 (https://github.com/mvschwarz/openrig,
Apache-2.0). Planned changes: the web UI, Slack gateway, bundles, cross-host, cmux and Pi/OMP support
are removed; an OpenCode adapter is added; storage uses a new schema. Ported files carry a header
stating they were derived and modified.

# rig-rs (working name)

A Rust port of [OpenRig](https://github.com/mvschwarz/openrig), in progress.

**Status:** scaffold only. There is no ported code yet, and the crate layout is still being designed. The product name is a placeholder and will change; it will not be "OpenRig".
